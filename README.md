Heart Disease Prediction System
A machine learning pipeline and Streamlit web app to predict heart disease.
Data Source: Indian Cardiovascular Disease Dataset (Mendeley Data).
Developed by: Arpan Das, Chandan Kumar Mishra, and MD Belal (BACET).
Files Included:
- train_model.py: ML training pipeline.
- app.py: Streamlit interactive dashboard.
- heart.csv: The dataset used for training and testing.
- requirements.txt: Python dependencies.
How to Run:
1. Install requirements: pip install -r requirements.txt
2. Train the model: python train_model.py
3. Start the app: streamlit run app.py
